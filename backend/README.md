# Backend — API de Consulta de Clima

API en Laravel 13 que consulta OpenWeatherMap, guarda el historial y acepta comentarios.

Las instrucciones de instalación, los endpoints y las decisiones de diseño están en el
[README de la raíz del repositorio](../README.md).

Atajos:

```bash
composer install
php artisan migrate
php artisan serve     # http://localhost:8000
php artisan test
```
